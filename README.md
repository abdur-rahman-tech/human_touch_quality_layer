# Human Touch Quality Layer

An AI-powered communication quality-control application built with Python, Streamlit, and Groq.

Human Touch Quality Layer evaluates whether a message feels genuinely human, thoughtful, natural, personalized, context-aware, and aligned with the requested brand voice.

> **Important:** This is not a definitive AI detector. A high or low score does not prove whether a message was written by a human or generated by AI. It is a communication-quality signal.

## Features

- Evaluate emails, social-media posts, customer-service responses, and business messages.
- Human-Touch Score from 0–100.
- Empathy score.
- Naturalness score.
- Personalization score.
- Context-awareness score.
- Brand-voice score.
- Evidence-based potential concerns.
- Recommended changes.
- Recommended rewrite.
- Secure Groq API key handling.
- Streamlit-ready deployment.
- Reproducible weighted overall scoring.

## How scoring works

The Groq model evaluates five dimensions from 0–100:

| Dimension | Weight |
|---|---:|
| Empathy | 20% |
| Naturalness | 25% |
| Personalization | 20% |
| Context Awareness | 25% |
| Brand Voice | 10% |

The application calculates the final score:

`Overall = Empathy × 0.20 + Naturalness × 0.25 + Personalization × 0.20 + Context Awareness × 0.25 + Brand Voice × 0.10`

Verdict thresholds:

- **80–100:** Strong
- **50–79:** Needs Improvement
- **0–49:** Weak

This is intentionally calculated in Python instead of asking the model to invent an overall score. This makes the final score consistent and reproducible.

## 9. How the secret is used by the application

The application checks Streamlit Secrets first:

```python
key = st.secrets.get("GROQ_API_KEY")
```

If a Streamlit secret is not available, it checks the environment variable:

```python
os.getenv("GROQ_API_KEY")
```

The resulting key is passed to the Groq Python client:

```python
client = Groq(api_key=api_key)
```

The application therefore expects the secret name to be exactly:

```text
GROQ_API_KEY
```

Do not change it in Streamlit unless you also change the Python code.

## 11. If you accidentally expose your API key

If a Groq API key is accidentally committed to GitHub or shared publicly:

1. Revoke/rotate the exposed key in the Groq console.
2. Create a new key.
3. Replace the Streamlit secret with the new key.
4. Remove the exposed key from the repository/history where appropriate.

Never assume that deleting the key from the latest commit makes an exposed credential safe.

## 13. Troubleshooting

### Error: GROQ_API_KEY is not configured

Check that the Streamlit secret is exactly:

```toml
GROQ_API_KEY = "your_groq_api_key"
```

Then save/redeploy the app.

### Error: model unavailable

Check the currently available Groq models and update `AVAILABLE_MODELS` in `app.py` if necessary.

Groq model documentation:
https://console.groq.com/docs/overview

### JSON parsing error

The application uses JSON mode plus an extraction fallback. If a model returns unexpected output, try another supported model or inspect the technical error shown by the application.

### Dependency error

Make sure Streamlit installs the dependencies from:

```text
requirements.txt
```

The current file contains:

```text
streamlit>=1.50,<2
groq>=0.37,<1
```

## Responsible use

The score should not be treated as an objective measurement of whether a person is sincere or whether a text was written by AI.

Language is context-dependent. Cultural differences, sarcasm, professional conventions, intentional brevity, and specialized terminology can affect the evaluation.

For legal, medical, financial, employment, or other high-stakes communication, use human review.
